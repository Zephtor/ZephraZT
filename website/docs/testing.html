BITTE VORHER LESEN

Nur in einer
Wegwerf-VM.

!

Der Installer ist experimentell und nicht für echte Hardware freigegeben. Installiere Zephra OS nicht auf deinem Arbeitsrechner oder auf einem Datenträger mit wichtigen Daten.

Vor dem Start

  • Verwende GNOME Boxes, virt-manager oder eine andere Virtualisierungslösung.
  • Lege eine neue virtuelle Maschine mit einer leeren, entbehrlichen virtuellen Festplatte an.
  • Prüfe, dass keine Host-Laufwerke oder echten Datenträger an die VM durchgereicht werden.
  • Starte das Live-System zunächst nur zum Testen. Beginne keine Installation, solange der Installer nicht ausdrücklich für VM-Tests freigegeben ist.
  • Verwende nur ein ISO aus einer Quelle, der du vertraust; ein offizieller öffentlicher Download ist derzeit nicht eingerichtet.

Wenn Calamares nicht startet

Öffne im Live-System eine Konsole und starte Calamares mit Debug-Ausgabe:

pkexec /usr/bin/calamares -d

Die Fehlermeldung kann zeigen, ob Polkit, Branding, Modulkonfiguration oder ein anderes Problem den Start verhindert. Teile beim Melden eines Fehlers nach Möglichkeit auch die Calamares- und ISO-Version mit.

Vor einer Installation

Ein bootfähiges Live-System ist kein Nachweis dafür, dass die Installation funktioniert. Der Installer wurde noch nicht vollständig mit Installationsabschluss, Neustart und Prüfung des installierten Systems abgenommen. Warte auf eine ausdrückliche Freigabe und getestete Installationshinweise.
